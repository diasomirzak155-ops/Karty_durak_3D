# Карты Дурак Онлайн — 3D Club (сборка 4.3)

Мобильный веб-клиент карточной игры с 3D-столом и комнатами Socket.IO. Это исходный проект, не готовый APK.

## Что изменено в 4.3

- Одна контекстная игровая кнопка вместо отдельных кнопок «Взять» и «Бито»: в зависимости от состояния партии она показывает «Взять карты», «Перевести» или «Бито · следующий раунд».
- Карты в руке сортируются по масти и достоинству для более удобной игры на телефоне.
- Исправлена отправка подкидных карт: игроки, кроме защищающегося, могут подкидывать совпадающие достоинства во время защиты и после отбоя.
- Выбранная карта и режим перевода сбрасываются после подтверждённого изменения хода/руки, чтобы не оставалось старого выбора.
- При первом подключении игроку предлагается заполнить профиль; после первого сохранения профиля начисляется одноразовый бонус 1 000 000 виртуальных фишек.
- «Королевская игра» временно помечена как недоступная. Специальные правила ещё не реализованы, поэтому игра не выдаёт обычный подкидной режим за королевский.
- Обновлена версия сервера и добавлена smoke-проверка структуры проекта и локальных ресурсов.

## Что уже есть в проекте

- Главное меню: профиль, создание стола, вход по коду и настройки.
- Комнаты с уникальным шестизначным кодом, выбором 2–6 игроков, взноса, оформления карт и колоды 24/36.
- Подкидной и переводной режимы.
- Профиль с именем и аватаром.
- Звуки и оригинальная фоновая музыка.
- Локальные игровые ресурсы: 4K-текстура сукна и дерева, четыре варианта рубашек, атлас лицевых карт, эмблема и иконки.
- 3D-стол, модели игроков, карты на столе, колода, козырь, лента действий и синхронизация игровых событий через Socket.IO.

## Проверка и запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run check
npm start
```

Откройте `http://localhost:3000`. Для игры с другом через интернет сервер нужно разместить на хостинге с поддержкой WebSocket/Socket.IO.

## Честный статус Android-сборки

Android APK в этой версии не создан и не протестирован. Для полноценной Android-сборки нужны установленные Capacitor-пакеты, Android SDK/Gradle и проверка на реальном телефоне. Three.js пока загружается с CDN, поэтому перед автономной сборкой его нужно включить локально. Онлайн-игра требует постоянно доступного сервера. Перед публикацией необходимы нагрузочные тесты, проверка переподключения и защита профилей/комнат.

Виртуальные фишки не являются деньгами; платежи не подключены. Специальные правила «Королевской игры» пока не реализованы.
