# Карты Дурак Онлайн — 3D Club v4.0

## Что есть в проекте
- Онлайн-комнаты на Socket.IO, 2–6 игроков, подкидной и переводной режимы.
- Серверная проверка ходов, козырей, отбивания, подкидывания и виртуальных ставок.
- Профили, баланс, победы/поражения и список друзей сохраняются в `data.json`.
- 3D-сцена Three.js: стол, текстуры дерева и сукна, объёмные карты, свет и тени.
- Процедурные 3D-персонажи с суставными руками и пальцами, жесты приветствия, 👍, 🖕 и аплодисменты; жесты синхронизируются между участниками.
- Имена и индикаторы подключения над местами игроков.
- Повторное подключение игрока к незавершённой комнате по коду, если сервер ещё хранит эту комнату.
- `/health` возвращает версию и состояние сервера.

## Запуск локально
Нужен Node.js 18 или новее.

```bash
npm install
npm start
```

Открой `http://localhost:3000`. Для игры вдвоём оба игрока открывают один и тот же адрес сервера; создатель передаёт код комнаты.

## Деплой на Render
- Runtime: Node
- Build command: `npm install`
- Start command: `npm start`
- После деплоя проверь `/health`.
- Чтобы профили и фишки переживали перезапуски, подключи Persistent Disk и задай `DATA_DIR` на путь диска (см. ниже).

По умолчанию `data.json` создаётся рядом с `server.js`. На Render без постоянного диска файловая система может очищаться при новом деплое.

## Важные ограничения
Это законченный для дальнейшей разработки игровой прототип, но не фотореалистичный AAA-релиз. Персонажи собраны процедурно из геометрии Three.js; для настоящего фотореализма нужны лицензированные GLB-модели высокого качества, PBR-текстуры, facial rig и motion-capture анимации. В текущем билде нет полноценной турнирной сетки, рейтингового матчмейкинга, античита, авторизации через OAuth и внешней базы данных. Данные комнат находятся в памяти и исчезают при перезапуске сервера; `data.json` хранит только профили и друзей. Виртуальные фишки не являются деньгами.

## Технические замечания
- Three.js загружается из jsDelivr CDN, поэтому клиенту нужен доступ к CDN.
- Для публичного релиза рекомендуется ограничить CORS, добавить rate limiting, проверку сессий и тесты игрового движка.
- Если игрок отключился во время партии, он может попробовать войти повторно по коду комнаты с того же браузерного профиля.
